02

How to drive Claude — read this first

The whole skill in seven rules
1One prompt, one change. Do the steps in order. Don't paste the next prompt until the current one works.
2Look, then say what you see. After each step, open the app in the browser. Tell Claude what actually happened — "the page is blank," "I see the form."
3Commit every win. When something works, tell Claude: "commit this with a short message." That's your save point to go back to.
4Errors are normal — paste them back. Copy the red error text and send it: "this errored, please fix it." Don't try to fix code yourself.
5Ask it to explain. Unsure what happened? "explain what you just changed in plain English." Understanding beats guessing.
6Stay in your folder. Each of you works in your own lab/ area on your own branch. If Claude offers to change something else, say no.
7Stuck for 15 min? Move the goalposts. Ask Claude to "make it work with fake data for now" and carry on. A visible slice beats a perfect one.

Before 09:30 — setup (do it with a helper if you can)

  • Claude Code open, inside the payroll-consulting repo, with the app running (pnpm dev in website/).
  • The Anthropic API key is in website/.env.local — ask your helper to confirm this; the AI steps need it.
  • Your own branch made. Prompt to paste: "make a new git branch called lab-elo" (or lab-bj).
  • Bj only: have your sample payroll spreadsheet ready (8 rows: employee id, classification, ordinary hours, Saturday hours, hourly rate, gross paid).

05

If it breaks · staying out of each other's way

Read before you panic
DOPaste the exact error text back to Claude and ask it to fix it. This is the normal loop.
DON'TEdit code files by hand. If you opened one, close it without saving.
DOFall back to fake data (Rule 7) if the AI or file-reading step won't behave. Keep the slice visible.
DON'TLet Claude change the questionnaire, reports, or database. Say: "only work inside my lab folder."
DOGo back to your last commit if things get messy: "undo my uncommitted changes."
DON'TTry Prompt 3. It's optional. A finished Step 2 is a full, successful day.
