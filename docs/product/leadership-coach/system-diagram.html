Leadership Coach: System Diagram

2026-08-11 · How data, agents, and routines fit together · Companion to the AI Program Plan v2 in this folder
The rule above the whole system: the agents prep and draft, the manager decides. Nothing an agent writes reaches a team member without passing a publish gate (shared recaps, OCEAN profiles), and no agent ever recommends promoting, managing out, ranking, or labeling a person.

All four run on Claude Opus (COACHING_CLAUDE_MODEL override available), write in the coach's voice from the foundation docs, never use em dashes, and fail soft: an error lands on the row, never blocks the cycle.

The loop, in one sentence

Routines wake the agents, the agents turn structured + unstructured data into preps, recaps, nudges, and trends, The manager holds the conversation and publishes what the team sees, and everything the conversation produces (transcript, commitments, mode split, new reads) flows back into the data that preps the next cycle.
